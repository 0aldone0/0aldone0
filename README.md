# Hi, I'm Aldo 👋

I develop .NET driver DLLs that bridge software and specialized hardware —
RF amplifiers, signal generators, GPIB adapters, IO controllers, and robot arms.
At home I automate everything I can.

---

## 🔧 What I build at work

- **Hardware driver DLLs** in C# / .NET — clean integration for measurement instruments
- **SCPI communication** over VISA, TCP, and serial (RS-232/USB)
- **Event-driven serial drivers** — Arduino, relay boards, GPIB-to-Ethernet adapters
- **Robot arm control** — TCP client for Universal Robots UR5e

## 🏠 What I build at home

- Smart home automation with Home Assistant, MQTT and Node-RED
- Sensor dashboards with InfluxDB + Grafana
- Custom Arduino and Raspberry Pi projects
